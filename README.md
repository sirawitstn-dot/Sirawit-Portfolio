## 🛠️ Featured Technical Highlights
- **Automotive Control Arm Analysis:** Static structural simulation, von Mises stress evaluation, and material benchmarking using ANSYS Workbench.
- **Active Solar Water Heater (IoT):** Differential temperature control system, thermistor telemetry, and embedded local web server via ESP32.
- **2D Chassis Layout Modeling:** Tractor semi-trailer wheelbase and axle load distribution modeling implemented in Python (Matplotlib).
- **Surface CAD Modeling:** Sports helmet design utilizing CATIA V5 Generative Shape Design.
