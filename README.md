# Sirawit-Portfolio

This is a personal mechanical engineering portfolio website for internship applications.

## Files
- `index.html` — main portfolio page
- `styles.css` — styling
- `script.js` — small script for dynamic footer year

## How to view
Open `index.html` in a browser, or run a simple local server such as:

```bash
python -m http.server 8000
```

Then open: `http://localhost:8000`

## Customize
- Replace `your.email@example.com` with your real email address.
- Update the project examples with your actual internship-related work.
- Add your own technical strengths, skills, and internship goals.
